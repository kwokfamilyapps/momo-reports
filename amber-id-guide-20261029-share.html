2. 四步決策樹（唔使儀器，10 分鐘完成）

第一步：飽和鹽水（1 杯水 + 7 湯匙鹽，拌到溶唔晒）
   ├─ 沉底  → 係玻璃或黃玉髓（唔係琥珀系）→ 睇光澤：銳利小亮點＝玻璃；微晶霧感＝玉髓 → 完成
   └─ 浮起  → 繼續第二步

第二步：熱針（燒熱針尖，只掂孔道內側，開窗通風）
   ├─ 松香味／樹脂甜香 → 琥珀系 → 第三步
   ├─ 刺鼻化學味      → 塑料仿品 → 完成
   └─ 完全無反應唔熔   → 玻璃（同第一步結果對照）→ 完成

第三步：透光睇內部（電筒側後方 30–45°，唔好正對鏡頭）
   ├─ 見自然波浪流淌紋 + 霧狀雲，無粒狀邊界 → 天然蜜蠟／琥珀 → 第四步確認
   └─ 見粒狀／碎片邊界、成排氣泡、色塊界線 → 二代壓製蜜蠟 → 完成

第四步：365nm 紫外燈
   ├─ 藍白／藍綠柔和螢光 → 支持天然
   └─ 艷藍、均勻呆板、或全無 → 可疑，再用酒精棉抹（柯巴會發黏）

3. 三個測試嘅正確做法（同常見錯法）

① 飽和鹽水

  • 做法：1 杯微溫水加約 7 湯匙食鹽，拌到有鹽沉底；放珠落去，等 10 秒。
  • 錯法：用「鹹水」但濃度不足 → 真琥珀都沉底，誤判。
  • 局限：只可以排除玻璃／玉髓；二代壓製、柯巴、聚苯乙烯塑料一樣浮。

② 熱針（微破壞，最後做）

  • 做法：針尖用打火機燒紅 → 離開火源等 2 秒 → 掂孔道內側或背面不顯眼處。
  • 錯法：直接用火燒珠面 → 一定留黑疤；或喺密封房間做 → 吸入塑料煙。
  • 安全：開窗、遠離紙巾等易燃物；唔好用嚟測未確定嘅黃色礦物（雌黃／雄黃含砷，加熱會放毒氣）。

③ 透光

  • 做法：電筒平放枱面向上，珠放側邊 30–45°；關室內燈；手機曝光調 −1 至 −2；白紙做背景。
  • 錯法：光源正對鏡頭 → 全片過曝，內部結構完全睇唔到（我實測過，過曝張相乜都睇唔出）。

附加：密度試（有電子磅就最準）

  • 量珠直徑（mm）＋重量（g）：15 mm 珠若 1.8–2.0 g＝琥珀系；4.4 g 以上＝玻璃／玉髓。
  • 口訣：同尺寸，琥珀比玻璃輕一半以上。

5. 如果係真蜜蠟：保養四條

  • 莫氏只有 2–2.5 → 獨立軟袋，唔好同金屬／其他石頭一袋
  • 忌酒精、香水、洗甲水、超聲波清洗機（會溶蝕表層光澤）
  • 只可以微溫清水＋軟布抹，抹完即乾
  • 忌長時間暴曬、高溫（車內、暖爐旁）→ 會起龜裂網紋；平時戴住「盤」係最好保養
