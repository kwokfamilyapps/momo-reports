已核實：.venv 其餘檔案完好、uv 嘅 base Python 3.11 完好（python.exe / pythonw.exe 都在）、新 venv 嘅 python 都在。只有舊 .venv\Scripts 嗰兩隻唔見。呢個模式唔似 uv / pip 操作（嗰啲會連 shim 一齊重寫），最似外部程序（防毒隔離／清理工具）拎走兩隻直譯器。

所以 42,929 次全部即刻失敗。WScript 嘅錯誤描述係空字串，所以 log 只有 ERROR spawning gateway: ，連原因都冇得睇。

③ Watchdog 嘅「死亡偵測」本身係盲嘅

舊邏輯用「有冇 hermes.exe 或 pythonw.exe 呢個名嘅 process」判斷 gateway 生死。你部機長期有其他 hermes.exe（桌面 app 相關）→ 就算真 gateway 死咗，佢都會以為「仲行緊」而唔去救。
